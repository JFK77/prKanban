7. DATA FLOW ANALYSIS
================================================================================

Authentication Flow:
   1. Page load
   2. Firebase Auth Check (onAuthStateChanged)
   3a. User found → Load board
   3b. No user → Show login modal
   4. User clicks Google Login or Guest Login
   5. OAuth/Anonymous auth succeeds
   6. Retrieve userId, userName, photoURL
   7. Load tasks for user

Read Flow:
   1. After authentication
   2. getDocs(collection(db, 'tasks'))
   3. Render tasks in UI
   4. Apply filters (owner, customer, tags)
   5. Display in board layout

Write Flow:
   1. User performs UI action (create/edit/delete)
   2. Frontend validation
   3. Try Firebase write operation
   4. Success → UI update + LocalStorage backup
   5. Error → LocalStorage fallback + error toast
   6. Offline → LocalStorage + "sync pending" indicator
